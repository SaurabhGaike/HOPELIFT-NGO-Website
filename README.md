# 🌱 HOPELIFT — NGO Website

A modern, responsive **NGO landing page** built to present an organization's mission, projects, impact, volunteer opportunities, donation options, testimonials, gallery, and latest updates.

🔗 **Live Demo:** https://saurabhgaike.github.io/DemoNGO/

---

## 📌 About the Project

**HOPELIFT** is a demo NGO website focused on empowering communities through education, healthcare, environmental conservation, community empowerment, emergency response, and women's empowerment.

The project was created as a frontend web-development project with a clean, modern design and interactive UI elements.

---

## ✨ Features

### 🏠 Hero Section
- Strong NGO mission statement
- Call-to-action buttons
- Full-screen background image
- Responsive layout

### 📊 Impact Statistics
- 15K+ lives impacted
- 50+ active schools
- 100K trees planted
- 20+ health camps

### ℹ️ About Us
- Organization story
- Mission and vision
- Timeline of major milestones
- Founder message

### 💼 Projects
- Education for All
- Healthcare Access
- Green Future
- Community Empowerment
- Emergency Response
- Women's Empowerment

### 🙋 Volunteer Section
- Volunteer benefits
- Registration form
- Skills and interests
- Availability selection
- Client-side success message

> **Note:** The volunteer form is currently a frontend/demo form and does not send data to a backend.

### 💚 Donation Section
- Predefined donation amounts
- Custom donation amount
- Donation form UI
- Security/SSL messaging for the demo interface

> **Note:** The donation form is a frontend/demo interface and does not process real payments.

### 💬 Testimonials
- Multiple testimonials
- Interactive slider
- Automatic slide rotation

### 🖼️ Impact Gallery
- Project gallery
- Category filtering
- Education, Environment, and Health filters

### 📰 Latest Updates
Sample NGO news and project updates covering education, tree planting, healthcare, women's skill development, volunteer stories, and disaster response.

### 🌙 Dark Mode
- Light/dark theme toggle
- Preference saved using `localStorage`
- Desktop and mobile support

### 📱 Responsive Design
Designed for desktop, tablet, and mobile screens.

### ✨ Scroll Animations
Uses the browser's `IntersectionObserver` API to reveal content as the user scrolls.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/SaurabhGaike/DemoNGO.git
```

### 2. Open the project

```bash
cd DemoNGO
```

### 3. Run the website

Because this is a static website, you can open `index.html` directly in your browser.

For development, you can also use the **Live Server** extension in VS Code.
